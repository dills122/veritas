# Security reports

Veritas is currently a `0.1.0-rc.0` candidate. Security fixes are handled against the current candidate; no long-term support policy is established yet.

Report vulnerabilities through [GitHub private vulnerability reporting](https://github.com/dills122/veritas/security/advisories/new). Include the version/commit, Node and OS versions, a minimal reproduction and the affected ownership, input-validation or recovery boundary. Remove credentials and private source material. Use public issues for ordinary bugs without sensitive exploit details.

Preserving unmanaged/edited files and never executing imported skill scripts are core safety invariants. Runtime compatibility and certification limits are documented in [the compatibility matrix](docs/compatibility.md).
